# Smart Museum Artifact Conservation System

## Task 1 — System Operations

The following operations are performed by the Smart Museum Artifact Conservation System.

### O1 — Perform System Self-Check
The system checks whether all essential sensors and environmental-control devices are functioning correctly.

### O2 — Verify Sensor Availability
The system verifies that required sensors are available and providing valid readings.

### O3 — Record Artifact Information
The system records the artifact identification information when an artifact is placed inside the chamber.

### O4 — Load Environmental Profile
The system loads the required environmental limits specified for the artifact.

### O5 — Monitor Environmental Conditions
The system continuously monitors temperature, humidity, light exposure, vibration, door status, artifact condition, and power availability.

### O6 — Verify Chamber Door Status
The system checks whether the chamber door is closed before activating normal conservation.

### O7 — Compare Temperature With Permitted Range
The system compares the current temperature with the permitted temperature range for the artifact.

### O8 — Correct Temperature
The system activates the environmental-control mechanism to restore temperature when it moves outside the permitted range.

### O9 — Verify Temperature Recovery
The system uses sensor readings to confirm that temperature has returned to the permitted range after correction.

### O10 — Compare Humidity With Permitted Range
The system compares the current humidity with the permitted humidity range for the artifact.

### O11 — Correct Humidity
The system activates the environmental-control mechanism to restore humidity when it moves outside the permitted range.

### O12 — Verify Humidity Recovery
The system uses sensor readings to confirm that humidity has returned to the permitted range after correction.

### O13 — Activate Protection Measures
The system reduces light exposure and activates additional environmental controls when an environmental condition cannot be corrected within the allowed recovery period.

### O14 — Generate Operator Alert
The system generates an alert for the museum operator when protection mode is activated.

### O15 — Detect Significant Vibration
The system detects significant vibration while an artifact is inside the chamber.

### O16 — Verify Vibration Stabilization
The system verifies that vibration remains below the permitted threshold for the required stabilization period.

### O17 — Suspend Conservation Activities
The system suspends normal conservation activities when the chamber door is opened or significant vibration is detected.

### O18 — Verify Safe Conditions
The system verifies artifact environmental conditions and sensor status before resuming normal conservation or allowing artifact removal.

### O19 — Switch to Emergency Power
The system switches to an emergency power source when normal power is lost and emergency power is available.

### O20 — Record Power Failure Incident
The system records a power failure incident when normal power is lost.

### O21 — Perform Safe Shutdown
The system safely shuts down when power is lost and emergency power is unavailable.

### O22 — Authorize Artifact Removal
The system permits artifact removal only when the chamber is confirmed to be in a safe condition and no active protection response is underway.
